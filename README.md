# MORIER LeadHunter

Telegram-бот для агентства посевов **MORIER**: сам находит рекламодателей с бюджетом, изучает их ИИ,
кладёт готовую карточку в очередь команды, раздаёт лиды по правилу первого клика, держит SLA первого
контакта и ведёт каденцию касаний, рейтинг и красный список контактов.

Бот **не пишет клиентам сам** — пишет человек. Автоспам с аккаунта убивает и аккаунт, и главное отличие
агентства: персонализацию.

## Что в репозитории

| Путь | Что это |
|---|---|
| `bot/` | Рабочий код бота: Python 3.12, aiogram 3, Telethon, SQLite. Точка входа — `bot/main.py` |
| `bot/README.md` | **Основная документация**: запуск, ключи Trustat, настройка сканера, ИИ, тесты |
| `bot/tests/` | Пять наборов тестов без сети и без Telegram |
| `docs/TZ_MORIER_LeadHunter_Bot.md` | Техническое задание v1.2 — зачем всё устроено именно так |
| `app/`, `components/` | Next.js-витрина проекта (обзор системы). Веб-дашборд из этапа 4 ТЗ ещё не начат |
| `.github/workflows/` | CI: тесты бота на каждый push и pull request |

## Быстрый запуск бота

```bash
cd bot
cp .env.example .env          # заполните BOT_TOKEN и OWNER_ID, остальное можно позже
docker compose up -d --build
docker compose logs -f        # ждём строку «Бот @... запущен»
```

Без Docker:

```bash
cd bot
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Дальше — раздел «Первые 10 минут после запуска» в [bot/README.md](bot/README.md): привязка группы лидов,
сотрудники, ключи Trustat, доноры, красный список.

## Тесты

Каждому прогону нужен свой пустой `DATA_DIR` — тесты сверяют счётчики квот и статусы ключей.

```bash
cd bot
for t in harness test_services test_trustat test_ai test_growth; do
  BOT_TOKEN=1:x OWNER_ID=1 AI_API_KEY=sk-test DATA_DIR="/tmp/lh-$t" .venv/bin/python -m "tests.$t"
done
```

`test_ai` и `test_growth` поднимают локальный сервер вместо DeepSeek, `test_trustat` — вместо
`api-public.trustat.me`. Реальные ключи и деньги не нужны.

## Состояние по этапам ТЗ

| Этап | Состояние |
|---|---|
| 1. Очередь и дисциплина | Готов, кроме квиза допуска новичка и таблицы каналов MORIER (`/catalog`, `/price`) |
| 2. Охотник (сканер, скоринг, пул ключей) | Готов |
| 3. Самообучение | Частично: few-shot в проверке черновика, автопоиск доноров, недельный отчёт, экономный режим ИИ. Скоринг v2 на scikit-learn и суфлёр по возражениям — нет |
| 4. Расширение | Не начат: платный Trustat и Telegram Ads, TGStat, PostgreSQL, веб-дашборд |

Осознанные отступления от ТЗ: ИИ вызывается напрямую по OpenAI-совместимому API (DeepSeek), а не через
Vercel AI Gateway; добавлена роль «байер»; схема БД упрощена (статусы, передача и сделка — поля в `leads`);
вместо APScheduler — собственный asyncio-цикл в `bot/app/scheduler.py`.

## Что нужно от владельца до запуска

Бот, отдельный аккаунт и SIM для сканера, ключ DeepSeek, группа лидов и чат для бэкапов, первые 50 каналов-доноров
и 20 ключевых слов, стартовый красный список. Подробности — в разделе «Этап 0» ТЗ.

## Безопасность

Секреты живут только в `bot/.env`, ключи Trustat в базе зашифрованы (`APP_SECRET` или автосозданный
`bot/data/.secret` — храните его вместе с бэкапами). В репозиторий не попадают `.env`, `data/` и файлы
сессии сканера. Доступ к боту — только по Telegram ID из белого списка, всем остальным бот молчит.
